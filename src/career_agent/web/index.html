Import public DOL LCA records

Download an LCA disclosure workbook from DOL performance data and export its disclosure sheet as UTF-8 CSV. Upload a file up to 8 MB here; use the documented CLI for larger files. No records are downloaded automatically.

USCIS employer decisions: refresh or import

Find a complete annual h1b_datahubexport-YYYY.csv file on the official USCIS data files page. Use its original URL, fiscal year and reporting cut-off date, not today's download date. No USCIS API token is required. Refresh contacts USCIS directly; if blocked, download the official file in your browser and import it below. Data is historical and may lag.

Import and review résumé text

Paste text or extract it locally from a PDF, Word or UTF-8 text file (up to 2 MB). Recognized section headings suggest a category for each line; choose a suggestion to review and edit as a fact. Nothing is sent to a model, saved or verified automatically. Scanned PDFs need OCR and are not supported.
