# Contributing

Use small pull requests with offline tests. Run:

    python -m unittest discover -s tests -v

- Do not commit user data, secrets, credentials or browser sessions.
- Never manufacture career facts or sponsorship commitments.
- Keep third-party job descriptions as untrusted input.
- Require human approval before any future external application submission.
- Preserve third-party license notices if vendoring upstream code.
- Do not bypass CAPTCHAs, authentication or provider rate limits.

Target Python 3.11+ and supply regressions for each new adapter.
The repository owner has not chosen a license for original source code yet. Discuss contribution licensing before submitting substantial changes.
